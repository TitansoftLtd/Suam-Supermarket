### Suam Supermarket

Suam Supermarket is a trusted retail destination offering a wide range of quality products at affordable prices.

### Installation

You can install this app using the [bench](https://github.com/frappe/bench) CLI:

```bash
bench get-app https://github.com/TitansoftLtd/Suam-Supermarket.git
```
```bash
bench --site {site_name} install-app suam_supermarket
```
